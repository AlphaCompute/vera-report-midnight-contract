# Vera Contract

This project is built on the Midnight Network.

## Overview

Vera smart contracts for the Midnight Network and TON blockchain.

## Contracts

- **`contracts/midnight/whistleblower.compact`** — Whistleblower evidence submission contract (Midnight Compact)
- **`contracts/midnight/vault.compact`** — Vault contract (Midnight Compact)
- **`contracts/midnit_ton.fc`** — TON FunC contract
- **`contracts/imports/stdlib.fc`** — TON standard library
